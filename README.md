# Car Content Kit

A static, mobile-first storefront for a $7 automotive creator digital product.

## Run locally

Open `index.html` in a browser, or use any static web server.

## Publish for free

This folder is suitable for static hosting services such as GitHub Pages or Cloudflare Pages.

## Before accepting payments

1. Create the actual digital product file.
2. Configure a payment provider that supports your situation.
3. Replace the `checkout.html` link in `index.html` with the provider's hosted checkout URL.
4. Configure secure digital delivery.
5. Test the full customer flow.

Do not collect card numbers in this static site. Payment accounts and marketplaces may have age and identity requirements. If you are under 18, a parent/guardian may need to own or manage the account depending on the provider's rules.
